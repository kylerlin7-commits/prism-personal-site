# 棱镜轨迹 · AI 工作流工具箱

免费样本：把一个重复任务，整理成可以尝试的工作流。

## 先选一个任务

| 问题 | 你的填写 |
|---|---|
| 工作中反复出现的任务是什么？ | |
| 谁会使用最终结果？ | |
| 输入是什么：文字、文档、表格或图片？ | |
| 需要交付什么，怎样判断合格？ | |
| 一周出现几次，现在哪一步最费时间？ | |
| 哪些环节必须由人判断？ | |
| 可使用哪些资料，权限来自哪里？ | |
| 哪些信息不适合上传？ | |

## 把任务拆成流程

收到输入 → 提取关键字段 → 检索资料 → 形成初稿 → 人工核对 → 输出结果 → 保留记录

根据具体任务删减步骤，先做最少的环节。

## 工具选型

- 单次整理与写作：先用对话式工具检验输入与输出。
- 重复批量处理：考虑表格字段、自动化与结构化输出。
- 有固定知识范围：先把资料结构、来源与更新责任理清。
- 需要调用系统：确认 API、身份与权限，再引入工具调用。
- 涉及对外发送、审批或改数据：保留人工确认与执行记录。

## 一份可改的指令框架

```text
任务：……

输入资料与授权范围：……
处理步骤：……
输出格式：……
必须保留的来源信息：……
不确定时怎样处理：……
需要由人确认的地方：……
```
