# 棱镜轨迹 · 个人知识库方法包

免费样本：把收集过的资料，变成下次找得到、用得上的知识。

## 不先囤资料，先想用处

- 我最常需要回答的三个问题：
- 我在什么任务里会用到这些资料：
- 什么资料会过期，谁负责更新：
- 怎样判断检索结果真的有用：

## 最小知识结构

| 字段 | 用途 |
|---|---|
| 标题 | 一句话知道是什么 |
| 来源与链接 | 下次能回到原文核对 |
| 主题 | 对应你的工作任务或研究问题 |
| 摘要 | 只写可复用的核心内容 |
| 日期与版本 | 区分新旧信息 |
| 可靠程度 | 原始来源、转述、个人判断 |
| 应用记录 | 曾在哪个问题上使用 |
| 下一次检查 | 需要更新时有入口 |

## 四个使用动作

1. 收集：保留原始链接与日期，不只保存摘要。
2. 整理：围绕任务分类，而不是不断增加文件夹。
3. 检索：先写一个真实问题，观察能否找到相关资料与出处。
4. 复盘：把使用结果与缺口写回，删除重复或过期资料。

## 知识库与 AI

- 先确认资料可使用的范围与权限。
- 问答需要给出来源；不知道时说明不知道。
- 不同来源有冲突时保留差异，不用生成文本替代核实。
- 用常见问题作为测试样例，记录命中与遗漏。
- 涉及系统动作时，将检索、建议与执行分开验证。

## 这周的一步

挑一个主题，先整理少量最常用资料。提出三个真实问题，用结果检查结构是否合适。
