# 棱镜轨迹 · 职业与项目叙事

免费样本：从一个目标岗位倒推，把已有经历说清楚。

## 目标岗位差距

| 岗位要求 | 我已有的证据 | 还缺什么 | 下一步补齐动作 |
|---|---|---|---|
| | | | |

先挑三个最核心要求，不要一次补齐所有能力。

## 一个项目故事

- 场景与目标：为什么要做？
- 核心问题：卡在哪里？
- 我的职责：我具体负责什么？
- 行动与取舍：选择了怎样的做法，为什么？
- 结果证据：有哪些可核对的事实与交付？
- 复盘：下次可以怎么改进？

## 检查叙事

- 是否只说“参与”，没有说个人贡献？
- 是否堆工具名，没有说明解决的问题？
- 是否有结果，但没有口径和来源？
- 是否能回答为什么做、为什么这样做、做得怎样？
